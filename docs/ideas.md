# Parking lot

Ideas deliberately not being built now. Nothing here is committed to; this exists so
good ideas stop competing with the current milestone.

## Sandbox mode

Unlimited dish, no eras, no arc — set initial conditions and watch a population evolve
under whatever pressures you configure. Close to a pure biology simulation. Cheap to add
once the simulation engine exists, since it is the same engine with the progression
layer switched off. Considered and set aside on 2026-09-22 because a sandbox has no
story that develops, which is central to the main game.
